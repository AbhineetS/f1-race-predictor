## 🏁 Overview

F1 Live Leaderboard is a real-time Formula 1 dashboard designed to provide race information in a clean, professional, and visually engaging format.

The project focuses on combining:

- ⚡ Live race data
- 🏎️ Driver standings
- 📊 Session analytics
- 🌤️ Weather information
- 🎨 Premium Formula 1 inspired UI
- 📱 Responsive dashboard experience

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/AbhineetS/f1-race-predictor.git

cd f1-race-predictor
```

### Backend Setup

```bash
cd backend

python3 -m venv venv

source venv/bin/activate

pip install fastapi uvicorn requests pandas

uvicorn main:app --reload
```

Backend:

```text
http://127.0.0.1:8000
```

### Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend:

```text
http://localhost:5173
```
